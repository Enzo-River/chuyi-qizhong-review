# 初一上 · 期中/期末在线复习（生物 / 历史 / 道法 / 地理）

把 2026-2027 学年第一学期期中复习资料按学科分门别类整理成的**纯静态在线复习站**，并按教材目录扩展到期末全册；地理为按湘教版 2024 版教材自主整理。

每科顶部可在 **期中范围 / 期末全册** 之间切换：期中范围只显示当时考到的内容，期末全册显示新增章节 + 全册串讲 + **3 套模拟卷** + 题型专项突破，末尾「期中回顾」保留已复习板块。

全站共 **85 个板块、620 道选择题、125 道主观题**（期中原卷内容 + 期末自主整理）。
无需构建、无需后端、无需联网，直接打开 `index.html` 就能用；部署到 GitHub Pages 后可手机随时复习。

在线地址：<https://enzo-river.github.io/chuyi-qizhong-review/>

## 功能

- 四科分栏 + **期中 / 期末范围切换**，移动端适配
- 全站搜索（点顶栏 🔍 或 `Ctrl/Cmd + K`）
- 选择题即时判分、错题筛选、重做（地理每题附解析）
- 抽背卡片随机抽取、显示/隐藏答案
- 「遮罩速记」盖住知识点，点一下揭开
- 深浅色主题切换
- 复习进度保存在本机浏览器 `localStorage`，不上传任何数据

## 本地使用

```bash
# 方式一：直接双击 index.html（所有数据以 <script> 内联加载，file:// 也能用）
# 方式二：起一个本地服务
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```
